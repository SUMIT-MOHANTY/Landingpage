# Browser Compatibility Testing Guide

This document outlines the process for testing the landing page across different browsers and devices to ensure consistent functionality and appearance.

## Supported Browsers

Our landing page should be tested and fully functional on:

- Chrome (latest 2 versions)
- Firefox (latest 2 versions)
- Safari (latest 2 versions)
- Edge (latest 2 versions)
- Mobile browsers (iOS Safari, Android Chrome)
