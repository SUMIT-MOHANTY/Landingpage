# Accessibility Compliance Checklist

## WCAG 2.1 Compliance Targets
- [ ] Level A (Minimum) - Must meet
- [ ] Level AA - Should meet
- [ ] Level AAA - Nice to have

## Testing Tools
- Automated tools (Lighthouse, axe, WAVE)
- Screen reader testing (NVDA, VoiceOver)
- Keyboard navigation testing
- Manual contrast checking

## Checklist

### Perceivable
- [ ] All images have alt text
- [ ] Videos have captions
- [ ] Content can be presented in different ways
- [ ] Content is easy to see and hear
- [ ] Color is not used as the only means of conveying information
- [ ] Text has sufficient contrast against background

### Operable
- [ ] All functionality is keyboard accessible
- [ ] Users have enough time to read and use content
- [ ] Content does not cause seizures or physical reactions
- [ ] Users can easily navigate and find content
- [ ] Users can use different input methods beyond keyboard

### Understandable
- [ ] Text is readable and understandable
- [ ] Content appears and operates in predictable ways
- [ ] Users are helped to avoid and correct mistakes

### Robust
- [ ] Content is compatible with current and future tools
- [ ] HTML is properly nested and follows standards
- [ ] ARIA is used appropriately when needed
- [ ] Custom controls have proper roles and states
